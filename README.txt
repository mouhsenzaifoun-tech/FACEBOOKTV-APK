FacebookTV - Facebook as an app on Android TV / TV box

GET THE APK WITHOUT ANDROID STUDIO (GitHub, free)
1. Create a free account at github.com and make a new repository.
2. Upload ALL the files of this folder to it (including the hidden .github folder).
3. Open the repository's "Actions" tab > "Build APK" > "Run workflow".
4. After 3-5 minutes open the finished run and download "FacebookTV-apk" (a zip containing app-debug.apk).

INSTALL ON THE TV BOX
- Copy app-debug.apk to a USB stick, or use "Send Files to TV".
- Open it with a file manager on the box. Allow "install unknown apps" if asked.

REMOTE CONTROLS
- Arrow keys : move the cursor
- Up/Down at the screen edge : scroll the page
- OK / Enter : click
- Back : go back (exits on the first page)
- Menu : go to Facebook home
- Channel +/- : page up / page down
